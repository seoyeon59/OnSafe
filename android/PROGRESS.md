# OnSafe 프론트엔드 진행 현황

**기준일** 2026-10-14 · **작성** 프론트엔드

핵심 파이프라인(로그인 → 촬영 → 낙상 감지 → 이력 확인)과 보호자 실시간 영상(LIVE)까지 코드 구현 완료.
남은 것은 실서버 두 기기 검증과 백엔드 계약 합의.

---

## 1. 앱 구조

```
로그인 ─┬─ 회원가입 (2단계)
        └─ 로그인 성공
              ↓
         튜토리얼 → 권한 요청 → 모드 선택
                                   ├─ 보호자 모드 → 홈(위험 지수·LIVE) · 사고 이력 · 알림 · 설정
                                   └─ 카메라 모드 → 촬영 · 낙상 감지 · LIVE 송출
```

**페어링** 보호자·피보호자가 각자 계정으로 로그인한 뒤 6자리 코드로 1:1 연결.
보호자 화면(위험 지수·기기·사고 이력·영상·삭제)은 연결된 피보호자 ID 기준 조회, 알림함만 보호자 본인 ID 기준.

---

## 2. 기능별 상태

| 기능 | 상태 | 비고 |
|---|---|---|
| 회원가입 · 로그인 · 계정 찾기 · 탈퇴 | ✅ | 주소 선택 입력은 [#68](https://github.com/seoyeon59/OnSafe/pull/68) 병합 대기 |
| 온보딩 (튜토리얼 5장 · 권한 · 모드 선택) | ✅ | |
| 카메라 촬영 · 관절 전송 · 낙상 감지 · 녹화 | ✅ | 화면보호기 · 가로 양방향 회전 포함 |
| 페어링 · 연결 해제 | ✅ | |
| 사고 이력 · 영상 · 알림함 · 푸시 | ✅ | 사고 확인은 연결된 피보호자 ID로 요청 |
| 보호자 LIVE 시청 | ✅ | 30초 영상 대기, 포그라운드 동안 약 4분마다 연장, 이탈·백그라운드 시 종료 |
| 피보호자 LIVE 송출 | ✅ | 분석 프레임을 LiveKit 커스텀 소스로 송출, "보호자가 보는 중" 배지 |
| 영상 동의 | ✅ | 승인 창 선택 항목, 카메라 모드 보호자 옆 눈 토글, 철회 즉시 송출 중단 |
| 시청 시작 소리·진동 | ⏸ | 적용 보류. `CameraModeActivity`의 `LiveWatchAlert.play` 주석 해제 시 적용 |

## 3. 남은 작업

| 항목 | 내용 |
|---|---|
| 실서버 E2E | 별도 계정 두 기기로 LIVE 시작·연장·종료, 동의 철회·연결 해제 시 끊김, 송출 중 낙상 감지·클립 업로드 |
| 동의 이어받기 정책 | 재페어링 시 값을 바꾼 경우에만 `live_video_enabled` 전송. API 스펙 v4.16("항상 전송")과 합의 필요 |
| 백엔드 요청 | 보호자 사고 삭제 권한, LIVE `expires_at` 시간대, 알림 `event`·`elder_user_id`, 없는 경로 404 |
| 배포 전 확인 | 릴리즈 서명·난독화 빌드, 운영 API 주소, Firebase·LiveKit 설정, 주소 검색 운영키 |

## 4. 개발 참고

- `design/icon_source` 편집용 SVG 원본, `app/src/main/res/drawable` 앱이 읽는 VectorDrawable. 이후 XML로 직접 만든 아이콘은 SVG 원본 없음
- 보관 기간(사고 30일·알림 7일)은 서버 처리, 기간 지난 이력은 `404 LOG_NOT_FOUND`
